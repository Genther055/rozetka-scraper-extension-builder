# Фіксація відображення ціни зі знижкою на платформі та в Excel

Ми змінюємо логіку відображення так, щоб колонка «Ціна зі знижкою» (актуальна ціна продажу) завжди показувала числове значення вартості, а в Excel-таблиці заголовки та дані повністю відповідали інтерфейсу.

## Заплановані зміни

### 🎨 1. Шаблон дашборду (`src/app/components/dashboard/dashboard.html`)
* **Відображення «Ціни зі знижкою»:** Замість відображення прочерку `—` при відсутності знижки, колонка «Ціна зі знижкою» тепер завжди виводитиме `item.price ₴`.
* **Відображення «Ціни без знижки»:** Якщо знижка є, показуємо стару ціну закресленою. Якщо знижки немає, показуємо звичайну ціну без закреслення.

---

### 📊 2. Експорт до Excel (`src/app/components/dashboard/dashboard.ts`)
* **Оновлення заголовків:** Перейменовуємо та перевпорядковуємо базові заголовки Excel:
  * Першою йде колонка **«Ціна без знижки (грн)»** (`p.oldPrice || p.price`).
  * Другою йде колонка **«Ціна зі знижкою (грн)»** (`p.price`).
  * Третьою йде колонка **«Знижка (%)»** (`p.discount%` або `0%`).

---

## План верифікації

### Автоматичні тести
- Запуск `npm run build` для перевірки коректності компіляції TypeScript та Angular шаблону.

### Ручне тестування
- Перевірка, що колонка «Ціна зі знижкою» на платформі більше не містить прочерків для товарів без знижки, а показує актуальну ціну.
- Експорт даних в Excel та перевірка, що назви стовпців збігаються з дашбордом, а значення заповнені коректно.
