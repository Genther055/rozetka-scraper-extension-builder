# TradeScout OS — Аналітична платформа для Rozetka

Професійна система для збору товарів, аналізу ринкового попиту та автоматичного аудиту характеристик за допомогою штучного інтелекту Gemini.

---

## 🚀 Як запустити проект локально (Інструкція для розробника)

Щоб запустити платформу на вашому комп'ютері, виконайте наступні 4 кроки:

### Крок 1. Передумови (Prerequisites)
Переконайтеся, що на вашому комп'ютері встановлено **Node.js** (версії 18 або новіше).

### Крок 2. Встановлення залежностей
Відкрийте консоль у папці проекту та виконайте команду для завантаження всіх бібліотек:
```bash
npm install
```

### Крок 3. Налаштування ключів API (.env)
1. В корені проекту знайдіть або створіть файл з назвою `.env`.
2. Запишіть у нього ваш ключ API від Google Gemini (для роботи ШІ-Аудитора):
   ```env
   GEMINI_API_KEY="ВАШ_КЛЮЧ_GEMINI_API_HERE"
   APP_URL="http://localhost:4000"
   ```
   *(Файл `.env` автоматично внесено до `.gitignore`, тому ваш ключ ніколи не потрапить на GitHub)*.

### Крок 4. Запуск серверів
Запустіть платформу однією командою в консолі:
```bash
npm run dev
```
Ця команда одночасно запустить:
*   **Бекенд (Express API-сервер):** працює на порту `4000` (приймає та обробляє дані).
*   **Фронтенд (Angular-дашборд):** працює на порту `3000` (візуалізує дані).

Платформа відкриється за адресою: **`http://localhost:3000`**
*   **Логін:** `admin`
*   **Пароль:** `admin`

## 🔌 Як підключити та використовувати розширення Chrome

1. Відкрийте ваш кабінет **TradeScout** (у верхньому правому кутку натисніть синю кнопку **«Завантажити розширення (.zip)»**).
2. Розархівуйте завантажений архів `tradescout-extension.zip` у зручне місце.
3. Перейдіть у браузері Chrome за посиланням: `chrome://extensions/`
4. Увімкніть **«Режим розробника»** (Developer mode) у верхньому правому кутку.
5. Натисніть кнопку **«Load unpacked»** (Завантажити розпаковане розширення) у верхньому лівому кутку та виберіть папку, яку ви розархівували.
6. Перейдіть на будь-яку сторінку категорії Rozetka (наприклад, повербанки), відкрийте вікно розширення, переконайтеся, що адреса вебхука вказана як `http://localhost:4000/api/products`, та натисніть **«Запустити»**.
7. Після завершення збору ви отримаєте сповіщення, а дані з'являться на вашому дашборді!

## 🌐 Як розгорнути проект на Vercel

1. Завантажте цей репозиторій на свій GitHub.
2. Створіть новий проект у кабінеті **Vercel** та імпортуйте цей репозиторій.
3. У налаштуваннях проекту Vercel (**Settings** ➡️ **Environment Variables**) додайте змінну:
   *   **Name:** `GEMINI_API_KEY`
   *   **Value:** *ваш ключ Gemini API*
4. Запустіть розгортання. Angular додаток успішно збереться завдяки налаштованому файлу `vercel.json`.
5. Бекенд Express за замовчуванням продовжить працювати локально на вашому ПК (порт `4000`), обробляючи та зберігаючи дані у файл `data/products.json`.
