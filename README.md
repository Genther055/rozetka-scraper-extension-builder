# TradeScout — Аналітика товарів з Rozetka

Простий інструмент для збору товарів з Rozetka, оцінки попиту та аналізу характеристик за допомогою штучного інтелекту.

## Як почати роботу з програмою:

### Крок 1. Перейдіть на сайт дашборду
Відкрийте посилання на ваш опублікований дашборд у браузері:
👉 **[rozetka-scraper-extension-builder.vercel.app](https://rozetka-scraper-extension-builder.vercel.app)**

Для входу використовуйте ці дані:
* **Логін:** `admin`
* **Пароль:** `admin`

---

### Крок 2. Завантажте та встановіть розширення для Chrome
1. Увійшовши на сайт, натисніть фіолетову кнопку **«Завантажити розширення (.zip)»** у правому верхньому кутку.
2. Розархівуйте завантажений файл `tradescout-extension.zip` у будь-яку папку на комп'ютері.
3. Відкрийте браузер Google Chrome і перейдіть за адресою: `chrome://extensions/`
4. У правому верхньому кутку увімкніть тумблер **«Режим розробника»** (Developer mode).
5. У лівому верхньому кутку натисніть кнопку **«Load unpacked»** (Завантажити розпаковане розширення) та виберіть папку, яку ви щойно розархівували.
6. Переконайтеся, що розширення з'явилося у вашому списку та закріпіть його на панелі браузера.

---

### Крок 3. Налаштуйте розширення та запустіть збір
1. Перейдіть на сайт **Rozetka.com.ua** на сторінку будь-якої категорії товарів (наприклад, повербанки чи навушники).
2. Натисніть на іконку нашого розширення на панелі браузера.
3. У поле **«URL Вебхука n8n»** вставте це посилання на хмарний сервер:
   `https://rozetka-scraper-extension-builder.onrender.com/api/products`
4. Натисніть кнопку **«Запустити»**.
5. Програма сама прокрутить сторінку вниз, збере всі товари та завантажить їх на ваш сайт. Після завершення ви отримаєте спливаюче сповіщення в браузері.

---

### Крок 4. Дивіться аналітику
Поверніться на вкладку вашого дашборду (посилання з Кроку 1). Всі зібрані товари вже будуть там!
Ви зможете фільтрувати їх, бачити орієнтовну кількість продажів за місяць та запускати ШІ-аудит характеристик.
